# Contributing

Thanks for your interest in this skill.

## Status

This is a personal skill that reflects how I actually ship software. It's published openly so others can borrow ideas or use it as-is, but it's curated on my own schedule and according to my own opinions about how the work should be done.

## If you find a bug

Open an issue with:

- The trigger phrase or context that activated the skill
- What the skill did
- What you expected instead

## If you have a suggestion

Open an issue describing the change you'd like. I'll respond when I have time — silence is not a no.

If the change fits how I actually use the skill, I'll merge it. If it changes the skill's opinions or expands scope, I'm likely to thank you and not merge — that's not a judgment on the idea, just on whether it belongs in *this* version of the skill. Feel free to fork.

## If you send a PR

- Keep the change focused on one concern.
- Match the existing tone in `SKILL.md` and `README.md`.
- Don't add commented-out alternatives, "see also" links to your own work, or anything that doesn't pull its weight.
- I may rewrite the PR description before merging to keep the commit log readable.

## Pairing with other skills

This skill is designed to compose with sibling skills (see `README.md` for the family). If your change would break that composition or require coordinated changes in a sibling, mention the sibling in the issue or PR.
